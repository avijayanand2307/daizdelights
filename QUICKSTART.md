## 🎨 Customize Your Site

### Change Colors
Edit `styles.css` lines 7-14:
```css
:root {
    --primary-color: #8B4513;      /* Main brown */
    --accent-color: #FF6B6B;       /* Accent red */
    /* ... other colors */
}
```

### Change Text
Edit `index.html` to customize:
- Site title
- Product names & prices
- Contact information
- About section text

### Add/Remove Products
In `index.html`, copy and modify product cards:
```html
<div class="product-card">
    <!-- Copy existing product card -->
</div>
```

## 🌐 Deploy Online (Free Options)

### Option 1: GitHub Pages (Free Forever)
1. Create GitHub account
2. Create new repository named `daiz-delights`
3. Upload all files
4. Go to Settings → Pages → Deploy from branch
5. Your site: `yourname.github.io/daiz-delights`

### Option 2: Netlify (Free)
1. Go to netlify.com
2. Drag & drop entire project folder
3. Site goes live instantly!
4. Gets free `.netlify.app` domain

### Option 3: Vercel (Free)
1. Go to vercel.com
2. Upload project
3. Get live URL immediately

## 🆘 Need Help?

### Images not showing?
- Check file names are **exactly** as listed above
- Check images are in the `images/` folder
- Try clearing browser cache (Ctrl+F5)

### Styling looks weird?
- Make sure `styles.css` is in the root folder
- Clear browser cache
- Try a different browser

### Form not working?
- Forms show success message (backend setup needed for real emails)
- Check browser console for errors
